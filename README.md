# Tile Talk Tees – static website

Plain HTML/CSS, no build step. Deploy the contents of this folder to any free static host (GitHub Pages, Netlify, Cloudflare Pages). Not yet deployed.

## 1. Set the base URL
Every canonical tag, Open Graph/Twitter URL, JSON-LD URL, `sitemap.xml` and `robots.txt` uses the token:

    https://jjj2838.github.io/tiletalktees

Replace it (no trailing slash) with the real address, e.g. `https://tiletalktees.github.io`:

    grep -rl 'REPLACE-WITH-SITE-URL' . | xargs sed -i 's#https://jjj2838.github.io/tiletalktees#https://tiletalktees.github.io#g'

If the site lives in a sub-path (e.g. `https://user.github.io/tile-talk-tees`), use that full path. Note: GitHub Pages' 404.html uses relative links, so it styles correctly only for missing pages at the site root; serve from a user/org site (`name.github.io`) or a custom domain for best results.

## 2. Swap the placeholder Amazon links
No Amazon listings exist yet. Every Amazon button is:

    <!-- TODO: replace href="#" ... -->
    <a class="btn btn-amz is-placeholder" href="#" aria-disabled="true" data-amazon-placeholder="SLUG">Coming soon to Amazon</a>

Find them with `grep -n 'data-amazon-placeholder' *.html`. For each live listing: set `href` to the real Amazon URL, change the label to `Shop on Amazon`, and remove `is-placeholder`, `aria-disabled` and the TODO comment. `data-amazon-placeholder="storefront"` (home hero) is for the brand/storefront link.
